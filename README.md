# OctoPrint Light Control - TPLink
Adds TPLink Smart Plug support to OctoPrint-LightControl as a sub-plugin

## Setup
- Install the plugin using Plugin Manager from Settings
- Configure this plugin
- Select this plugin as a Switching and Sensing method in [Light Control](https://github.com/arbeaman/OctoPrint-LightControl)
